# Python-Basics-for-Data-Reading-Exploring-a-Dataset
Python and Pandas project for loading, cleaning, exploring, filtering, and analyzing a student exam results dataset using Jupyter Notebook.
# Week 2 – Student Exam Results Analysis

This project focuses on learning the fundamentals of Python and Pandas for data analysis. 
A dataset containing 1,000 student exam records is loaded, explored, cleaned, filtered, 
and summarized using a Jupyter Notebook.

## Key Tasks

- Load and explore the dataset using Pandas
- Check dataset shape, information, and statistics
- Identify and handle missing values
- Create Pass/Fail grades based on student scores
- Identify students who scored 90 or above
- Calculate average scores by subject
- Analyze scores by gender
- Count students in each subject
- Export the cleaned dataset to CSV
- Export subject-wise summary to Excel

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- Anaconda

## Project Files

- `Week2_StudentAnalysis.ipynb` – Main analysis notebook
- `student_scores.csv` – Original dataset
- `cleaned_students.csv` – Cleaned dataset
- `subject_summary.xlsx` – Subject-wise score summary
